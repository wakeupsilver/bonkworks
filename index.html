Bonkworks

Pin gadgets to the wall, link each one to the next, and press GO. A marble trips a mousetrap, which yanks a string, which pops a balloon…

How to build a contraption

  1. Start with a starter. Anything with ▶ (a marble hopper, an alarm clock, a big red button) goes off when you press GO!
  2. Click a part on the board, then pick the next one from the list. Parts that react to what this one does float to the top. Parts that won't react are greyed out, with the reason.
  3. Picked parts land where they should be hit and get linked automatically. Drag them around to fine-tune. Ropes 🪢 and wires ⚡ can reach far; balls and dominoes need to actually hit.
  4. Press GO! Watch the chain. If it stalls, nudge parts and try again, or leave 🪄 Assist on for a helping hand.
  5. Short on ideas? 🎲 Generate builds a random machine for you.

Keys: Space = GO / reset · Del = delete · F = flip · Q/E = rotate · L = link · Esc = deselect · drag empty space to pan, scroll to zoom
